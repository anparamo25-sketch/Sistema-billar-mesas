# Compilar Billar Control Pro desde un celular

1. Descarga este ZIP y descomprímelo.
2. Crea un repositorio nuevo en GitHub, por ejemplo `billar-control-pro`.
3. Sube al repositorio los archivos y carpetas que están dentro de `billar_control_final/` (no subas solamente el ZIP).
4. Abre la pestaña **Actions**.
5. Selecciona **Billar Control Pro - APK**.
6. Pulsa **Run workflow**.
7. Espera el check verde.
8. Entra en la ejecución terminada y busca **Artifacts**.
9. Descarga `Billar-Control-Pro-v3.0-APK`.
10. Descomprime el artifact y encontrarás `Billar-Control-Pro-v3.0.apk`.

El workflow crea automáticamente la carpeta Android, configura permiso de Internet y permite tráfico HTTP/WebSocket local para que las tablets se comuniquen por Wi-Fi.
